# ✨ TextPad — React Text Editor

TextPad is a simple, clean, and fast text editor built using **React + Vite**.  
It allows users to format text, count words/characters, switch themes, and use keyboard shortcuts for a smoother writing experience.

---

## 🚀 Live Demo  
🔗 https://lnkd.in/gYRi8Mic

---

## 🛠️ Features

- 🔤 Convert text to **Uppercase / Lowercase / Trim / Reverse**
- 📋 Copy text to clipboard
- 🧮 Live **Word & Character count**
- 🌗 Dark / Light mode toggle
- ⌨️ Keyboard shortcuts
- ⚡ Fast build & hot reload using Vite
